# BloomScript 🌸

**Learn JavaScript in Full Bloom** — Activity 1: JavaScript Basics.

A beginner-friendly JavaScript learning website with a soft, Monet-inspired garden design. Learn at your own pace through clear explanations, everyday analogies, and interactive examples.

## Learning topics

- **Variables:** `var`, `let`, `const`, data types, and assignment.
- **Objects:** properties, methods, nested objects, and built-in objects.
- **Arrays:** indexes, array operations, iteration, and transformations.
- **Functions:** declarations, expressions, arrow functions, parameters, and return values.

## Main features

- 17 lessons with explanations, code examples, expected outputs, and helpful tips.
- Editable JavaScript examples running in a sandboxed iframe.
- Four topic quizzes with scores, answer feedback, and retry.
- Completed lessons and best quiz scores saved locally in your browser.
- Searchable lessons, expandable chapter navigation, and previous/next controls.
- Responsive dashboard with a local painting, pastel cards, and a collapsible mobile sidebar.

The playground displays `console.log()` output and errors. Avoid infinite loops: the editor cannot reliably stop blocking code.

## Technologies

HTML5, CSS3, and vanilla JavaScript. No packages, build step, backend, database, or login are required. Progress uses localStorage. The painting is stored locally at `assets/painting.png`; optional Google Fonts have system-font fallbacks.

## Run locally

1. Open the project folder in VS Code.
2. Install **Live Server** by **Ritwick Dey** if needed.
3. Right-click `index.html` and select **Open with Live Server**.

Alternatively, open `index.html` directly in a modern browser. Live Server is recommended for consistent browser storage behavior. Use the same hostname and port to retain saved progress; clearing site storage removes it.
